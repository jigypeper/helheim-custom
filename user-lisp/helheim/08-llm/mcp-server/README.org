* helheim-mcp-server

This module installs [[https://github.com/rhblind/emacs-mcp-server][emacs-mcp-server]] (vendored offline in
=site-lisp/mcp-server/=) — a pure Elisp MCP server for Emacs.

** Enable
#+begin_src emacs-lisp
(require 'helheim-mcp-server)
#+end_src

See [[https://github.com/rhblind/emacs-mcp-server][emacs-mcp-server documentation]] on how to configure your agent (or ask it
to do it itself). The GitHub Copilot CLI supports MCP servers, so it can call
into this Emacs instance the same way any other MCP client would.

** Hacks

- Do not ask about killing mcp-server process on exit.
